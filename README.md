## Setup Instructions

**It is a terminal UI: run it interactively**, with your kubeconfig mounted read-only:

```bash
podman run --rm -it -v ~/.kube/config:/kubeconfig:ro ghcr.io/daemonless/k9s:latest
```

kubectl is in the image too: `podman run --rm -it -v ~/.kube/config:/kubeconfig:ro --entrypoint kubectl ghcr.io/daemonless/k9s:latest get pods -A`.

**The image runs as uid 1000.** A kubeconfig that only its owner can read (the usual `0600`) must belong to uid 1000, or be readable by it; otherwise k9s stops with `permission denied` on `/kubeconfig`. Copy it somewhere readable, or add `--user 0`.

**A kubeconfig that points at localhost** (a cluster on this same machine) needs `--network host`, so that address means the host and not the container.

Settings, skins, plugins and k9s's own logs go to `/config`; mount it to keep them between runs.
